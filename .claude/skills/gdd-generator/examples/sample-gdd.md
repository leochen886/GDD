# 杀戮尖塔（Slay the Spire）— 游戏设计文档（逆向范例）

> **说明：** 本文档是从成品游戏逆向推导的 GDD 范例，用于展示一份 MVP 游戏设计文档应该长什么样。
>
> **标注说明：**
> - 🔵 **已知事实** — 来自开发者公开发言、GDC 演讲、访谈等信息源
> - 🟡 **推测设计** — 基于游戏表现反推的设计逻辑，实际设计过程可能不同
>
> **阅读提示：** 如果你是第一次看 GDD，注意每个章节的**目的**——它不是在描述"这个游戏有什么"，而是在回答"设计者当时做了什么决策、为什么这么做"。

---

## 1. 游戏概述

### 一句话描述
> 🔵 一款融合 Roguelike 关卡爬塔与卡牌构筑的单机 deck-building 游戏。

### 核心勾子
> 🔵 每次爬塔都是全新的——随机生成的地图路线、随机的卡牌奖励、随机的遗物组合，让每一局的 build 体验都不同。没有两局游戏是相同的。

### 基本信息

| 项目 | 内容 |
|------|------|
| 游戏类型 | 🔵 Roguelike 卡牌构筑（Deck-building Roguelike） |
| 目标平台 | 🔵 PC → Switch → 手机（逐步移植） |
| 对标作品 | 🟡 《Dominion》（卡组构筑机制）+ 《FTL》（Roguelike 地图路线选择）|
| 目标受众 | 🔵 喜欢策略卡牌 + Roguelike 的硬核玩家 |
| 商业模式 | 🔵 买断制（PC $24.99） |

## 2. 核心玩法

### 核心循环

```
🔵 地图选路 → 进入房间（战斗/商店/事件/休息）→ 战斗胜利拿卡/遗物
→ 构筑卡组 → 挑战更强的敌人 → 推进地图层级 → 击败 Boss → 进入下一层 → 重复
```

🟡 这是设计者从《FTL》借来的核心结构——把"选路线"作为局内 meta 决策层，每一跳都是一个有意义的选择。这在当时是一个非常聪明的嫁接。

### 内层循环（单局）

```
🔵 战斗：手牌管理 → 能量管理 → 打出卡牌 → 格挡/攻击/技能 → 结束回合
→ 敌人行动 → 抽牌进入下一回合 → 直到战斗结束
```

### 外层循环（跨局）

```
🔵 爬塔死亡 → 根据分数解锁新卡牌进入全局卡池
→ 解锁新角色（共 4 个）→ 解锁更高难度 Ascension（1-20 级）
→ 下局有更多卡牌和遗物可用 + 更高挑战
```

🟡 这里的设计非常克制——跨局解锁的不是"数值变强"，而是"选项变多"。这是 Roguelike 设计的经典智慧：让玩家觉得"这次我能试不同的东西"，而不是"这次我更强了所以更容易"。

### 核心乐趣来源

| 乐趣 | 🔵/🟡 | 说明 |
|------|--------|------|
| Build 多样性 | 🔵 | 每局根据拿到的卡和遗物，构筑完全不同的卡组 |
| 策略深度 | 🔵 | 选卡、选路、手牌管理，三层决策交织 |
| 知识积累 | 🔵 | 了解敌人模式、卡牌配合、遗物协同是成长路径 |
| 高风险决策 | 🟡 | 每次选卡都是永久性的，选错削弱卡组，产生紧张感 |

### 核心差异化

> 🔵 在《杀戮尖塔》之前，卡组构筑游戏（如《Dominion》）和 Roguelike 是两个独立品类。它的核心创新是**把卡组构筑作为"局内 Roguelike 成长"的载体**，而非局前预组——这意味着每一局不是在"执行一个既定的卡组"，而是在"即兴创作一个卡组"。

## 3. 游戏系统（MVP）

### 系统清单

| 系统 | MVP 范围 | 优先级 |
|------|----------|--------|
| 战斗系统 | 回合制卡牌战斗，手牌+能量+意图机制 | P0 |
| 地图系统 | 随机生成的分层路线图，玩家选择路线 | P0 |
| 卡牌系统 | 攻击/技能/能力三类卡牌，局内获取与构筑 | P0 |
| 遗物系统 | 被动效果物品，战斗/Boss/商店/事件获取 | P0 |
| 角色系统 | 初始 2 个角色（Ironclad + Silent），各有独立卡池 | P0 |
| 敌人 AI | 意图预告机制——敌人显示下回合要做什么 | P0 |
| 商店系统 | 用金币买卡/买遗物/删卡 | P1 |
| 事件系统 | 随机遭遇事件，文字选择，风险-收益 | P1 |
| 药水系统 | 一次性战斗消耗品 | P2 |

### 系统详述

#### 战斗系统

**功能概述：**
> 🔵 回合制卡牌战斗。玩家每回合抽满手牌，拥有 3 点能量，打出手牌消耗能量。未用完的格挡在回合结束时消失。敌人使用"意图"系统预告下回合行动。

**MVP 范围：**
- ✅ 攻击/技能/能力三种卡牌类型
- ✅ 3 能量 + 5 手牌基础配置
- ✅ 敌人意图图标（攻击/格挡/强化/debuff）
- ✅ 数值系统：HP、格挡、力量、敏捷、虚弱、易伤
- ❌ 非对称 PvP 模式
- ❌ 实时战斗
- 🔮 合作模式（从未实现）

**核心规则：**
- 🔵 能量：每回合 3 点，部分卡牌/遗物可增加
- 🔵 手牌：每回合抽满 5 张，回合结束弃掉未用卡牌，弃牌堆空了重洗
- 🔵 意图：敌人头顶显示下回合行动，玩家可以据此决定使用攻击还是格挡
- 🔵 状态卡：战斗中敌人塞入的负面卡牌（伤口、晕眩等），污染卡组

---

#### 地图系统

**功能概述：**
> 🔵 每层（Act）是一个随机生成的节点图。玩家从底部出发，每一跳选择一个相邻节点，逐步向 Boss 推进。

**MVP 范围：**
- ✅ 随机生成节点图（战斗/商店/事件/休息/精英/Boss）
- ✅ 玩家可见整层地图（但看不到节点具体内容）
- ✅ 每条路线有不同的风险-收益组合
- ✅ 3 层（Acts），每层终点是一个 Boss
- ❌ 无尽模式

---

#### 遗物系统

**功能概述：**
> 🔵 遗物是提供被动效果的物品，一旦获得永久生效（除部分一次性遗物）。遗物之间可以产生协同效应。

**MVP 范围：**
- ✅ 常规遗物（战斗中获取/商店购买）
- ✅ Boss 遗物（强力但有代价，如"每回合+1能量但不能再获得金币"）
- ✅ 初始遗物（每个角色自带）
- ✅ 事件专属遗物

---

### 系统间关系

```
🔵 地图选路 → 决定遇到什么类型的房间
   → 战斗房间 → 掉落卡牌（3选1）+ 金币 + 可能有遗物
   → 商店房间 → 用金币买卡/遗物/删卡/买药水
   → 事件房间 → 文字选择，可能获得卡牌/遗物/金币/诅咒
   → 休息房间 → 回血或升级一张卡
   → 精英房间 → 更难战斗但必掉遗物
   → Boss    → 必掉 Boss 遗物，通关进入下一层

所有系统都汇入核心：卡组构筑 —— 你在局内的每一个决定都在塑造你的卡组。
```

## 4. 关卡 & 内容（MVP 范围）

### 内容清单

| 内容类型 | MVP 数量 | 说明 |
|----------|----------|------|
| 层（Acts） | 🔵 3 层 | 每层不同主题和敌人池 |
| Boss | 🔵 每层 1 个（3 选 1 随机）| 共 3 个 Boss |
| 可玩角色 | 🔵 2 个（Ironclad + Silent）| 各有独立卡池 |
| 卡牌 | 🔵 ~150 张 | 含公共卡 + 角色专属卡 |
| 遗物 | 🔵 ~100 个 | 含通用 + 角色专属 |
| 敌人类型 | 🟡 ~30 种 | 普通 + 精英，每层不同敌人池 |
| 事件 | 🟡 ~30 个 | 每层有专属事件池 |

### 内容够验证核心循环吗？

> 🔵 Mega Crit 只有 2 个人开发。他们的 MVP 策略非常精准：**3 层 × 2 角色 × ~150 张卡**，内容量刚好能让玩家体验 50+ 小时不重复的 build 体验。关键是复用性——同一张卡在不同遗物配合下就是不同的体验，内容效率极高。

## 5. 数值框架

### 核心数值表

| 数值 | 说明 | 🔵/🟡 | 初始值/范围 |
|------|------|--------|-------------|
| HP | 角色生命值 | 🔵 | 70-80（因角色而异） |
| 能量/回合 | 每回合可用能量 | 🔵 | 3（Boss 遗物可到 4） |
| 手牌数/回合 | 每回合抽牌数 | 🔵 | 5 |
| 格挡 | 临时护盾，回合结束消失 | 🔵 | 基于卡牌数值 |
| 力量 | 攻击力加成 | 🔵 | 0 起始，可叠 |
| 敏捷 | 格挡加成 | 🔵 | 0 起始，可叠 |
| 金币 | 通用货币 | 🔵 | ~100 起始，随难度变化 |

### 难度曲线

> 🔵 Ascension 系统（1-20 级），每一级叠加一个小难度修正，如：
> - A1：精英出现更多
> - A10：起始卡组多一张诅咒
> - A20：最终 Boss 是双 Boss 连战

🟡 这是非常优雅的难度设计：不做"敌人血 × 1.5"这种粗暴数值，而是每个 Ascension 加一条规则，改变玩家的决策模型。玩家不是"打不过"而是"需要换打法"。

### 经济平衡基调

> 🟡 金币是稀缺资源。每层产出约 100-200 金，商店一次消费就耗掉大半。设计意图是：**让玩家永远觉得"要是我多 50 金就好了"**，但又不至于穷到什么都买不起。删卡（移除废牌）是最贵的操作，意味着优化卡组是有成本的。

## 6. UI/UX 框架

### 核心界面流程

```
🔵 主菜单 → 选角色 → 获得初始遗物 → 地图界面 → 选路进入房间
  → 战斗界面（地图→战斗，俯视视角过渡）
  → 战利品界面（3 选 1 卡牌）→ 回到地图 → ... → Boss → 下一层
  → 最终 Boss → 胜利/死亡 → 分数结算 → 解锁 → 主菜单
```

### HUD 关键信息

> 🔵 战斗界面同时显示：
> - 顶部：敌人 HP + 意图图标 + buff/debuff
> - 底部：手牌（展开排列）
> - 左下：角色 HP + 格挡 + 能量球
> - 右下：结束回合按钮
> - 可选：抽牌堆/弃牌堆数量

🟡 这个布局的要点是：**所有决策信息在一个屏幕内**。玩家不需要翻页或切换视图来做战斗决策。

### 界面清单（MVP）

| 界面 | 功能 | 优先级 |
|------|------|--------|
| 主菜单 | 开始游戏/继续/设置 | P0 |
| 角色选择 | 选角色 + 显示解锁信息 | P0 |
| 地图界面 | 节点图 + 路线选择 | P0 |
| 战斗界面 | 手牌/能量/HP/敌人/意图 | P0 |
| 战利品界面 | 3 选 1 卡牌 + 跳过选项 | P0 |
| 商店界面 | 买卡/遗物/药水 + 删卡 | P0 |
| 休息界面 | 回血 30% 或升级一张卡 | P1 |
| 事件界面 | 文字 + 选项 | P1 |
| 卡组查看 | 随时查看当前卡组 | P1 |
| 分数结算 | 计分 + 解锁展示 | P1 |

## 7. 世界观 & 美术方向

### 世界观一句话
> 🟡 一座不断变化的尖塔，爬上去的人会得到一切，但没有人能活着下来。

### 世界观简述
> 🟡 尖塔是一个神秘的存在，内部不断变化。玩家扮演一名攀登者，用卡牌（代表战斗技能和战术）对抗塔中的生物。世界观是"服务于机制的背景布"——重点不在讲一个复杂的故事，而是给爬塔 + 卡牌战斗一个说得通的框架。

🟡 Mega Crit 只有两个人（一个程序+一个美术/设计），他们明智地把叙事资源控制在"够用"的水平。事件文字和遗物描述承担了大部分世界观传达。

### 视觉风格

| 维度 | 关键词 |
|------|--------|
| 美术风格 | 🔵 2D 暗黑奇幻插画风 |
| 色调 | 🔵 暗色调，每层 Act 有独立色彩主题 |
| 参考美术 | 🟡 传统奇幻插画 + 暗黑漫画 |
| 情绪/氛围 | 🔵 压抑、紧张、探索感 |

## 8. MVP 范围清单

### ✅ MVP 内（必须做，否则核心循环不成立）

| 项目 | 为什么必须？ |
|------|-------------|
| 回合制卡牌战斗（手牌+能量系统） | 核心玩法载体，没有就没有游戏 |
| 随机地图路线选择 | 把"选择权"交给玩家，是 FTL 式 Roguelike 的灵魂 |
| 敌人意图预告系统 | 让战斗从"猜"变成"决策"，是策略深度的基础 |
| 2 个角色 + 独立卡池 | 1 个角色不够验证 build 多样性，2 个是最小验证单位 |
| 3 层 Acts + Boss | 1-2 层太短不够 build 展开，3 层是验证卡组强度的最小单位 |
| 卡牌/遗物/商店 | 构筑卡组的三个核心来源 |

### ❌ MVP 外（明确不做）

| 项目 | 为什么不现在做？ |
|------|-----------------|
| 更多角色（Defect, Watcher） | 2 个角色够验证核心循环，3-4 个可以 EA 阶段加 |
| Ascension 难度系统 | 核心体验没跑通之前，先不用做难度分层 |
| 每日挑战模式 | 需要在核心内容足够丰富之后才有意义 |
| 多语言本地化 | 英语先行 |
| 移动端适配 | PC 验证后再移植 |

### 🔮 待定

| 项目 | 什么时候决定？ |
|------|----------------|
| 第三角色（Defect） | EA 上线后看玩家是否需要更多角色 |
| 更多遗物和卡牌 | 核心卡池验证后进行内容扩展 |

### 📋 MVP 之后

| 优先级 | 项目 | 说明 |
|--------|------|------|
| 1 | 更多卡牌和遗物 | 丰富 build 多样性 |
| 2 | 新角色 | 增加新鲜感 |
| 3 | Ascension 难度 | 给通关玩家继续挑战 |
| 4 | 每日挑战 | 增加社区粘性 |
| 5 | 平台移植 | Switch/手机 |

---

> **逆向总结：** 《杀戮尖塔》是一个教科书级别的 MVP GDD 案例。Mega Crit 只有 2 个人，却开创了整个 Roguelike 卡牌构筑品类。关键在于：
> 1. **核心创新足够锋利**——卡组构筑 + Roguelike 的嫁接是前人没做好的
> 2. **MVP 范围极度克制**——2 个角色、3 层、~150 张卡，刚好够让核心循环发光
> 3. **内容复用性极高**——同一套系统，配合不同遗物/卡牌组合产生乘法效应
> 4. **UI 设计简单到极致**——所有决策信息在一个屏幕，不需要花哨的动画
>
> 如果你的 MVP 比《杀戮尖塔》还复杂，问自己一句：我能用更少的东西验证核心乐趣吗？
